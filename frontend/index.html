Setup Help

  1. Install platform-tools (includes adb)
  2. On phone: Settings → About → tap Build Number 7× → enable Developer Options
  3. Settings → Developer Options → enable USB Debugging
  4. Plug in via USB (or pair wireless: Developer → Wireless Debugging)
  5. Accept the RSA key prompt on your phone
